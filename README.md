The Automated Home Gardening App was developed using Android Studio and is designed to work in sync with real-time environmental sensors to assist users in managing their home gardens efficiently and intelligently. The app provides a seamless interface that connects with hardware sensors to monitor essential plant-care parameters like soil moisture, temperature, humidity, and sunlight exposure.

🔧 Key Features: 

Real-time Sensor Integration: The app communicates with sensors (via Bluetooth or Wi-Fi modules like ESP32/NodeMCU) to fetch live data from the garden.

Personalized Watering Recommendations: Based on moisture readings and weather forecasts, the app suggests or automates watering schedules for different plants.

Weather Forecast Integration: The app pulls real-time weather data to avoid unnecessary watering on rainy days.

Plant Management Dashboard: Users can track different plants, set watering preferences, and view historical sensor data for each plant.

Chatbot Assistant: A built-in chatbot helps users with plant care tips, troubleshooting, and quick access to app features.
